## Design language (from hoodie)

- **Palette:** black base, charcoal grey illustration, blood-red accents (moon, sword glow, blossoms, dragon eyes, torii, kanji), distressed off-white typography
- **Typography:** gritty stencil / distressed drip lettering (same energy as hoodie “NO FUCKS GIVEN”)
- **Front art:** kneeling armored knight / samurai on glowing red blade, pagoda in mist, cherry blossoms, blood moon
- **Back art:** coiled black dragon with glowing red eyes through gnarled tree and embers, torii over dark water
- **Accents:** vertical red kanji near hem; red hanko / seal stamps on back

## Print placement

| Zone | Location | Content |
|------|----------|---------|
| A | Front — left thigh (wearer’s left / viewer’s left on flat) | Knight + pagoda + blood moon scene |
| B | Front — right upper thigh | Distressed drip **`NFG`** |
| C | Front — lower left outer | Vertical red kanji |
| D | Back — upper seat / yoke | **Set A:** `NFG` · **Set B:** `NO FUCKS GIVEN` |
| E | Back — full legs | Dragon + tree + embers + torii / water |
| F | Back — lower outer | Vertical red kanji + seal stamps |

Recommended print method: DTG or all-over sublimation on black fleece / French terry. Keep typography high-contrast white; keep red accents saturated.

## Garment construction

### Men (cuffed)
- Elastic waistband + drawcord
- Tapered leg
- Ribbed elastic ankle cuffs
- Side pockets (optional zip); rear welt optional

### Women (open hem)
- Elastic waistband + drawcord
- Contoured hip / thigh, still tapered
- Clean open ankle hem — **no cuff**, no elastic gather
- Same pocket layout as men for matching sets

## Suggested materials

- Midweight black French terry or fleece (280–320 gsm)
- Soft brushed interior
- Color-matched drawcord
- Durable rib for men’s cuffs only

## Production notes

1. Treat front and back art as paired left/right panels so seams don’t cut through the dragon head or knight face.
2. Seat typography (`NFG` or `NO FUCKS GIVEN`) sits above the crotch seam and should read clearly when standing.
3. Women’s open hem should not flare into a wide-leg; keep a true jogger taper.
4. Do not place `NO FUCKS GIVEN` on Set B fronts — front text is **`NFG` only**.
5. Match hoodie distressed drip font for all wordmarks.
