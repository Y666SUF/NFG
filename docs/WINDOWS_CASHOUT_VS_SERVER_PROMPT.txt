## Step 2 — Add manual crash cashout to `server/game.js`

**This is NOT on GitHub `main` yet** — implement on PC (or merge if Mac pushed since this prompt).

### 2A. Add helper `_settleBetWin(user, bet, settleMult, opts = {})`

Place after `_finishRound` / before `_tick`. Shared settle logic for auto + manual cashout:

- Round `settleMult` to 2 decimals
- Reject if below `this.opts.minCashout` (usually 1.05)
- `grossPayout = floor(amount * mult)`, 5% tax on profit, credit user, add tax to pot
- Build win row with: `user`, `displayName`, `nameStyle`, `level`, `rank`, `result: "win"`, `grossPayout`, `payout`, `profit`, `tax`, `cashout: mult`, `targetCashout: bet.cashout`, `bet`, `manual: !!opts.manual`
- Award XP `CASHOUT_SUCCESS`, call `this.onCashoutWin(...)` in try/catch
- Return the row object

### 2B. Add `manualCashout(rawUser)`

- Only when `this.phase === PHASE.RUNNING`
- User must have active bet in `this.bets`
- Settle at **current** `this.multiplier` (floored to 2 decimals), not their target
- If mult < minCashout → `{ ok: false, reason: "too_early" }`
- Call `_settleBetWin(user, bet, settleMult, { manual: true })`
- Remove bet from `this.bets`, push row to `this._winsThisRound`, call `this.onUpdate()`
- Return `{ ok: true, user, displayName, balance, amount, cashout, targetCashout, grossPayout, payout, profit, tax, ... }`

### 2C. Refactor auto cashout in `_tick()`

Replace inline win-settle block (when `settleAt >= bet.cashout`) with:

```javascript
const row = this._settleBetWin(user, bet, bet.cashout);
if (row) {
  this._winsThisRound.push(row);
  resolved.push(user);
}
```

### 2D. Wire chat commands in `parseChatMessage`

Add **before** the jet-lock check (so players can cash out even when command-locked):

