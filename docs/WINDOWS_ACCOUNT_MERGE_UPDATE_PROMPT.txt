# NFG Crash — Windows PC update: TikTok link + account merge

Paste this into **Cursor on your Windows PC** (live server at https://y666suf.com).

## What changed

When a phone **app guest** links TikTok, the server now **combines both accounts**:

| Field | Merge rule |
|-------|------------|
| **Points balance** | **SUM** (e.g. 10k app + 400k TikTok = **410k**) |
| **All-time points** | SUM |
| **Level / XP** | **Higher** of the two |
| **Rank** | Recalculated from merged level |
| **Powerups** (steals, shields, etc.) | SUM charges |
| **Achievements / missions** | Union (keep both) |
| **Arcade progress** (Jump, Vault Run, Blocks) | Best scores max'd; Jump total earned summed; skins union'd |

iOS also migrates **local on-device** Jump/Vault shop + personal bests into the TikTok account on link.
