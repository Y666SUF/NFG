## If something fails

1. Check Node logs for `/api/mobile/auth/app-guest` 404 → old `mobile-auth.js`
2. Steal 401 → bearer token / session issue
3. Steal `steal_not_armed` → user has 0 steal charges (wallet/inventory)
4. Arcade errors → `mobile-arcade.js` missing or not registered
5. Compare PC `server/` file dates with git `main` — PC may be on stale branch

When done: set `docs/cross-device/pending-on-pc.md` frontmatter `cross_device_status: done` and push from PC if you changed anything locally.
